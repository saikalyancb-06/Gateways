## 📌 Overview

Conventional AI chatbots formulate static summaries based on generic web searches without epistemic skepticism. **ResearchOps** transforms this paradigm by deploying an **autonomous research organization** modeled after elite intelligence and strategy firms (McKinsey, DARPA, judicial review boards).

Instead of trusting the first search result, **ResearchOps**:
1. **Plans Dynamically**: The *Research Director* continuously diagnoses uncertainty and dynamically rewrites research plans as new data surfaces.
2. **Deploys Domain Specialists**: Parallel agents investigate market dynamics, competitor moats, customer friction, and statutory regulations.
3. **Adversarially Attacks Its Own Claims**: An *Adversarial Challenger* stress-tests assumptions, searching for counter-evidence and margin compression traps.
4. **Adjudicates Truth in Evidence Court**: An independent *Evidence Judge* arbitrates disagreements before claims are accepted.
5. **Audits Completed Research (Research Autopsy)**: Runs a second-order adversarial audit to discover hidden blind spots, stale evidence, and overconfidence.
6. **Accumulates Institutional Knowledge (Research Memory)**: Retains verified claims, canonical entities, source dependencies, and cross-investigation contradictions across 38+ enterprise projects.

## ⚡ 10 Core Epistemic Modules

ResearchOps features a full 10-tab command center designed for enterprise operators, strategists, and investors:

### `0. Research Planner` *(Autonomous Orchestration)*
- **Adaptive Research Director**: Continuously diagnoses epistemic uncertainty, re-allocating specialist agents in Round 1 $\rightarrow$ Round 2 $\rightarrow$ Round 3.
- **Saturation Detection**: Calculates research coverage percentage and budget burn to mathematically determine when sufficient evidence exists to stop.
- **Dependency & Replan History**: Auditable visual timeline of why tasks were spawned, reprioritized, or cancelled.

### `1. Investigation Workflow` *(Live Execution)*
- **Multi-Agent Terminal**: Real-time communication feed showing agent handoffs, discoveries, challenges, and verification results.
- **Preloaded Enterprise Scenarios**: Instant benchmarking presets (Indian Retail CV Automation, Quick-Service Loyalty Economics, Outpatient Clinic AI Copilots under DPDP Act 2023).

### `2. Board-Ready Report` *(Executive Synthesis)*
- **Executive Decision Briefing**: Comprehensive structured strategic report including unit economics, market size, regulatory risk registers, and phased implementation roadmaps.
- **Export & Print**: One-click clipboard copy and high-fidelity print-ready styling.

### `3. Claims & Evidence Debt` *(Verification Registry)*
- **Real vs. Unverified Status**: Live badges (`✓ Verified Real`, `⚠ Partially Verified`, `✗ Contested`).
- **Falsification Criteria ("What Would Change Our Mind?")**: Explicit criteria defining what counter-evidence would overturn each claim.

### `4. Evidence Court` *(Adversarial Arbitration)*
- **Courtroom Simulation**: Simulated judicial proceedings with **Prosecution**, **Defense**, **Evidence Clerk**, and **Presiding Judge**.
- **Interactive Claim Selector**: Select any claim to trigger simulated cross-examination and receive a binding judicial caveat.

### `5. Evidence Provenance Graph` *(Visual Knowledge Graph)*
- **Interactive SVG Canvas**: Visualizes provenance from **L1: Sources** $\rightarrow$ **L2: Claims** $\rightarrow$ **L3: Adversarial Challenges** $\rightarrow$ **L4: Binding Verdicts**.
- **Node Inspector**: Click any node to inspect raw publisher metadata, confidence ratings, and original source URLs.

### `6. Research Replay` *(Epistemic History)*
- **Time-Travel Scrubber**: Step-by-step playback of the entire investigation history without text truncation.
- **Auditable Provenance**: Pinpoints the exact moment an assumption was challenged and overturned.

### `7. Counterfactual Lab` *(What-If Simulator)*
- **Variable Perturbation Engine**: Test how changes in baseline assumptions (e.g. *What if minimum order value drops below ₹250?* or *What if compliance mandates on-premise edge storage?*) alter agent reactions and the judicial verdict.
- **Custom Hypothesis Simulator**: Type any scenario to watch agents recalculate viability metrics in real time.

### `8. Research Autopsy` *(Adversarial Post-Audit)*
- **Self-Attacking Audit**: A dedicated adversarial engine that stress-tests completed research to answer: *"How could this research be wrong, misleading, or overconfident?"*
- **Vulnerability Matrix**: Flags unsupported assumptions, single-source dependencies, outdated empirical telemetry, and generates recommended follow-up tasks.

### `9. Research Memory` *(Institutional Knowledge)*
- **Cross-Research Knowledge Store**: Retains structured intelligence across 38 prior investigations, 6,821 stored claims, and 1,204 sources.
- **Canonical Entity Resolution**: Normalizes aliases (e.g., `RBI` $\leftrightarrow$ `Reserve Bank of India` $\leftrightarrow$ `Central Bank`).
- **Chronological Claim Evolution**: Tracks claim drift and statement changes across 2024 $\rightarrow$ 2025 $\rightarrow$ 2026.
- **Cross-Database Contradiction Engine**: Identifies systemic disagreements across historical projects (temporal shifts vs. definition divergences) and provides one-click reconciliation.

## 🚀 Quickstart

### Prerequisites
- **Python**: 3.11+
- **Node.js**: 18+ (Node 20 recommended)
- **Ollama** *(Optional, for local inference)*: `ollama pull qwen3.5:9b`

### 1-Click Launch (Windows)
Double-click [`start_researchops.bat`](file:///D:/webman_researchops/start_researchops.bat) to launch all services simultaneously:
```cmd
start_researchops.bat
```
This automatically boots:
- Ollama Local Engine (if installed)
- FastAPI Multi-Agent Backend on `http://127.0.0.1:8000`
- Vite React Frontend on `http://localhost:5173`

---

### Manual Launch

#### 1. Backend Server
```bash
cd D:\webman_researchops
pip install fastapi uvicorn pydantic python-dotenv
python -m uvicorn researchops_core.backend.main:app --host 127.0.0.1 --port 8000 --reload
```
API Documentation (Swagger UI) is available at: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

#### 2. Frontend Application
```bash
cd D:\webman_researchops\researchops_core\frontend
npm install
npm run dev
```
Open your browser to: [http://localhost:5173](http://localhost:5173)

## ⚙️ Configuration (`.env`)

Create or update `.env` in the repository root:
```env
# Server
SERVER_HOST=127.0.0.1
SERVER_PORT=8000
FASTAPI_ENV=development

# Cloud Models (Groq / OpenAI / Anthropic / Gemini)
GROQ_API_KEY=your_groq_api_key_here
OPENAI_API_KEY=
ANTHROPIC_API_KEY=
GEMINI_API_KEY=

# Local Models (Ollama)
OLLAMA_BASE_URL=http://localhost:11434
DEFAULT_LOCAL_MODEL=qwen3.5:9b
DEFAULT_CLOUD_MODEL=qwen-2.5-32b
```
